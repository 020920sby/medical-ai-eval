# Medical AI Eval — 医疗 AI 健康助手安全与分诊质量评测

> 面向医疗 AI 健康助手的**分层评测体系**：用同一套样本与评分框架，评测商业产品、通用大模型，以及自建 Agent。
> 核心命题：**通用 benchmark 分数推不出医疗安全能力。**

---

## 这个项目回答什么

医疗 AI 已经进入千万用户的生活，但**没有独立的第三方评测**告诉用户：这些产品什么时候可以信任，什么时候必须小心。

本项目不评"哪个产品的模型更强"，而是评：

- 它在**什么场景下会出错**
- 出错**有多严重**（是否可能导致延误就医、错误用药）
- 它**知不知道自己的边界**

---

## 方法：三层评测 + 双轨对比

```
                   抓包 / 人工实测
                          │
                          ▼
              结构化（query · 回答 · 工具 · 引用）
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
   L1 规则层         L2 程序化层        L3 LLM-as-Judge
   分诊信号          行动提取·极性       rubric 打分
   红旗遗漏          结构校验·引用       （与人工校准）
        │                 │                 │
        └─────────────────┼─────────────────┘
                          ▼
              L2 与 L3 不一致 → 全部人工复核
                          │
                          ▼
              分桶统计 · bad case 归因 · 报告
```

**设计要点**：规则层只做**结构化事实提取**，不做语义判断；语义判断交给 LLM 层；两层不一致的样本全部人工过——因为不一致本身就说明该样本处在边界上。

---

## 双轨对比

| 轨道 | 测什么 | 工具 |
|------|--------|------|
| **通用能力** | 知识、推理 | lm-evaluation-harness（C-Eval 等） |
| **医疗安全** | 分诊质量、红旗识别、边界意识 | 本项目自建样本 + rubric |

两条轨的分数**并排呈现**，用同一批模型实证"通用 benchmark ≠ 医疗安全"。

---

## 评测对象

| 对象 | 方式 |
|------|------|
| 百小医（百川） | 会话流量分析 → 批量重放 → 三层评分 + 重复采样报方差 |
| 小荷 AI 医生（字节） | 人工多轮实测 |
| 蚂蚁阿福（蚂蚁） | 人工多轮实测 |
| Ortho Rehab Agent（自建） | 同一套 rubric 评 → 改进 → 复评（闭环） |

## 目录结构

```
.
├── docs/            分析文档、评测框架、对标分析
├── data/
│   ├── raw/         原始抓包（.gitignore，含内部字段不入库）
│   ├── samples/     评测样本（试卷，可迭代）
│   ├── test-records/实测记录（批改历史，不可改）
│   └── scoring/     评分汇总与统计
├── tools/           评测脚本（L2 程序化评测层等）
├── reports/         评测报告
├── portfolio/       作品集与面试材料
└── inputs/          外部素材来源索引
```

**设计原则**：`samples/` 是试卷，会持续迭代；`test-records/` 是批改历史，一旦记录不改。

## 局限性声明

- **小样本**：样本量远不能覆盖医疗场景的多样性，结论不代表产品的完整医学能力排名
- **特定版本**：结论仅针对测试时的产品版本，AI 模型更新频繁，结果可能很快过时
- **非临床环境**：评测以普通用户身份进行，不涉及真实医患关系与法律责任
- **来源边界**：产品信息来源于公开渠道与自身体验，不包含任何公司的内部数据或商业机密

本项目为独立个人研究，不代表任何机构，**不可作为医学决策依据**。
