## 素材使用纪律

1. **内部字段不入库**：凡含第三方产品内部 API 端点、字段结构、内部工具名的文件，一律放 `data/raw/`（已 gitignore），对外产出只保留清洗后的结构化结果
2. **素材是输入，不是产出**：本仓库只保留"我做了什么"，不搬运前序项目的文档
3. **引用要标来源**：报告里引用素材时标注文件路径
